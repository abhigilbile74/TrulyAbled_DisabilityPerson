# TruelyAbled – Assistive Flutter Application

TruelyAbled is a Flutter-based mobile application designed to empower people with disabilities by providing AI-powered accessibility, navigation, and emergency assistance. The application combines computer vision, speech technologies, and Google services to improve independence and safety in daily life.

## ✨ Features

### 🧠 Object Detection
- Detects nearby objects and obstacles in real time.
- Assists users in safe road crossing.
- Announces detected object names using **Text-to-Speech (flutter_tts)**.

### 💰 Currency Recognition
- Recognizes and validates currency notes.
- Helps visually impaired users identify money independently.

### 🗺️ Navigation Assistance
- Integrated **Google Maps API** for navigation.
- Provides optimized routes and nearby essential services:
  - Bus stands
  - Medical shops
  - Hospitals
  - Other important locations

### 🚨 Emergency SOS
- Activates with a **3-second tap**.
- Sends the user's live location to emergency contacts.
- Supports emergency response services including:
  - Police
  - Ambulance
  - Fire Brigade

### 📖 Text Recognition
- Uses **Google ML Kit** for Optical Character Recognition (OCR).
- Reads text from:
  - Books
  - Images
  - Documents

### ♿ Accessibility Tools
- Text-to-Speech (TTS)
- Speech-to-Text (STT)
- Shopping Assistant
- Reminders
- Voice-assisted interactions
